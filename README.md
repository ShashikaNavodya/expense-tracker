# Mintly — Money, made mindful

A responsive Flutter app for recording and managing everyday spending in US dollars.

## Features

- Dashboard with monthly spending totals, daily average, budget progress, category breakdown, and a six-month overview.
- Add, edit, and delete expense records with a date, category, and optional note.
- Search and filter the transaction history.
- Set and update a monthly spending budget.
- Add categories or remove unused categories.
- Save expenses, categories, and the budget locally on the device.

The app starts with a few clearly labeled example transactions so the dashboard is useful on first launch. They can be edited or deleted like any other expense.

## Run

```sh
flutter pub get
flutter run
```

## Check

```sh
flutter analyze
flutter test
flutter build web
```
